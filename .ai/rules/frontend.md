# Frontend rules (apps/web)

## Before writing code
- Check installed versions in `package.json` and use those APIs. TanStack Start moves fast; read its current docs, not memory.
- The owner runs `pnpm add`, generators, and `shadcn add`.

## Structure
- Routes in `src/routes/` (file-based). Route files stay thin: loader/guard + one page component.
- Feature code in `src/features/<feature>/`:
  - `api.ts` — typed calls through `api-client`
  - `query-keys.ts` — query key factory
  - `hooks.ts` — `useQuery` / `useMutation` / Echo hooks
  - `components/`
- Shared UI in `src/components/ui/` (shadcn/ui). Don't edit generated shadcn files beyond styling.
- `src/lib/api/schema.d.ts` is generated by `pnpm gen:api`. Never hand-edit it.

## Rendering
- Public pages (landing, login, register, password reset) are server-rendered.
- Logged-in area (`_app` layout and children) uses `ssr: false`.
- The `_app` route checks `/api/v1/me` and redirects to `/login` on 401.

## Data
- All server data goes through TanStack Query. No `useEffect` + `fetch`.
- Only `src/lib/api-client.ts` calls `fetch`. It sets `credentials: 'include'`, sends `X-XSRF-TOKEN`, `Accept: application/json`, `X-Socket-ID` (from Echo), and turns non-2xx into a typed `ApiError` (`message`, `errors`, `code`, `status`).
- Types come from the generated schema. No hand-written copies of API types.
- Query keys come from each feature's factory, e.g. `chatKeys.list()`, `messageKeys.list(id)`.
- Message history uses `useInfiniteQuery` with the API cursor.
- Sending uses an optimistic mutation: make a ULID (`ulid` package), add the message as `sending`, then replace with the server copy or mark `failed`.
- Live events update the cache with `setQueryData`; on Echo reconnect or tab focus, invalidate the open chat and the chat list.

## Components
- Function components + hooks. Props typed; no `any`.
- Server state lives in Query; local UI state in `useState`; no global store unless shared client-only state really appears.
- Forms show the API's 422 `errors` next to the right field.
- Message bodies are rendered as text (React escapes it). Links are detected and wrapped in `<a rel="noopener noreferrer" target="_blank">`. Never `dangerouslySetInnerHTML`.
- Times: receive ISO UTC, format with `Intl.DateTimeFormat` in the browser's locale.

## Style
- TypeScript `strict: true`.
- Biome for lint and format. `pnpm check` must pass.
- Tailwind v4 utility classes; design tokens in CSS variables; dark mode supported.
- Accessible: labelled inputs, buttons are `<button>`, focus visible, chat log uses `aria-live="polite"`.

## Env
- Only `VITE_*` variables reach the browser: `VITE_API_URL`, `VITE_REVERB_APP_KEY`, `VITE_REVERB_HOST`, `VITE_REVERB_PORT`, `VITE_REVERB_SCHEME`.
- Never put secrets in `VITE_*`.
